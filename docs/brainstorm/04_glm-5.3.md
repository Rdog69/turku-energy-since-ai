## 1. Thesis

The edge is **information asymmetry plus mechanism**. (i) The organisers state that unforecast wind changes are the main error driver, yet realised wind is not in the package — teams without the Fingrid real-time wind series are structurally blind to the *wind forecast error*, the one variable that is observable at the origin and persists across all 40 steps (the day-ahead forecast is frozen at 13:00). (ii) We model the price the way it is actually formed — one mixture CDF, `P(direction) × direction-conditional gap distribution`, respecting the June-2026 aFRR/VWAP rule — so p10/p50/p90, direction and spikes all come from a single coherent predictive distribution. (iii) Because each automatic metric is scored independently with no cross-column penalty, we select the best model source **per column** on rolling CV. We keep the crowd's core (LightGBM quantiles, conformal, recency weighting) and add these three layers on top.

## 2. Method

Work on `gap = price − spot` (spot is known for all 40 steps; verified). Build one predictive CDF per (origin, step):

**G(gap) = P(up)·F_up(gap) + P(down)·F_down(gap) + p_none·δ₀**, with p_none fixed ≈ 0.003 (true share 0.17%; predicting it costs more than it earns).

- **P(up), P(down):** LightGBM binary classifier (up vs down), log loss. Isotonic calibration per step band (1–4 / 5–12 / 13–40). Renormalise with p_none.
- **F_up, F_down:** LightGBM quantile regression at q ∈ {0.05, 0.1, 0.25, 0.5, 0.75, 0.9, 0.95}, trained only on up-/down-labelled quarters respectively. Target winsorised at ±500 for stability (spike *labels* from raw gaps). Interpolate the grid into a CDF; empirical tails beyond q=0.05/0.95.
- **Submitted columns:** p10/p50/p90 = spot + G⁻¹(q); `p_spike_high` = P(up)·(1−F_up(50)) + P(down)·(1−F_down(50)); `p_spike_low` analogous at −50. One G ⇒ all columns mutually consistent by construction.
- **Per-column selection:** also train direct gap quantiles (q=0.1/0.5/0.9) and direct spike classifiers. On two-fold rolling CV, pick the better source for each scored column (metrics are independent; only enforce p10 ≤ p50 ≤ p90 by sorting and probability sums by renormalising).
- **Calibration:** split conformal on validation residuals of G⁻¹(0.1)/G⁻¹(0.9), grouped by direction-probability decile × step band; target coverage 0.79–0.81 (baseline is 0.68 — big headroom). Check coverage per step band, not just overall.

**Features:**
- *Frozen DA block (all steps):* spot level; Δspot q-over-q and h-over-h; spot's position within the daily min–max; DA wind, consumption, solar; residual load (consumption − wind − solar); local hour/weekday/holiday; steps-into-next-day flag.
- *Nowcast block (with step decay / lag index):* last usable gap; last usable mFRR up/down marginal prices and activated MW (5–8 quarters back); aFRR-active flag and aFRR price (impute spot when missing); consumption forecast error; cross-border flow deviations; nuclear level; **wind error = real-time wind − DA wind forecast for the aligned quarter (MW, %, 4-quarter trend)** — the centrepiece.
- *NWP second opinion:* latest usable Open-Meteo ECMWF/ICON run: west-coast wind at the target quarter minus DA wind ("divergence"); |ECMWF − ICON| spread; icing proxy (T ∈ [−6, 2] °C, high humidity).
- *Time structure:* step as explicit feature; "info age" = quarters since newest usable observation.

**Extras:** recency sample weights (2–3× for Sep–Oct; ablate); train on all quarter-hour origins (4× rows); at steps 1–4, test blending p50 with **spot-differenced price persistence** (p50 = last usable price + spot_t − spot_last), which can beat gap persistence when spot jumps.

Why small margins matter: points = weight × (B − T)/(B − best). If best-team MAE is 38 and ours 37.5 while a rival sits at 40, we take 30 vs their 27.9. Per-metric selection also means we can win columns piecemeal. **Honest caveat:** these are judgement calls from the facts given, not measurements; the only firmly supported facts are the wind-quintile spread (mean |gap| 40.0 vs 13.6) and the organisers' hint.

## 5. Experiment plan

Roles: P1 harness/eval, P2 external data, P3 models, P4 calibration, P5 report/dashboard. Wall-clock ~34 h.

1. **H0–2 (P1, blocking):** leak-safe origin builder (assert every feature row's `first_usable_origin_utc ≤ origin`; log newest usable quarter per series), rolling two-fold CV (Sep 7–20 / Sep 21–Oct 4), metric suite, submission writer, format tests. Nothing runs before this passes.
2. **H0–3 (P2, parallel):** email organisers (real-time delay); fetch Fingrid real-time + Open-Meteo runs; cache to parquet. **Go/no-go for the whole thesis (H3–4):** autocorrelation of wind forecast error at lags 1–10 h ≥ ~0.5, and wind error at usable lag predicting future direction/gap better than no-wind baseline. If it fails, the edge collapses to the mixture + calibration — still worth building.
3. **H2–6 (P3):** crowd baseline (LGBM gap quantiles + direction + spike classifiers, package features only). Record numbers — this is the bar to beat.
4. **H4–10 (P3):** add wind-error, aFRR, activated-MW features. Keep a feature only if it improves MAE ≥ 0.5 or any Brier ≥ 0.003 on *both* CV folds.
5. **H6–12 (P3):** mixture model (direction classifier + per-direction quantile grid + CDF assembly). Compare per column vs direct models.
6. **H12–16 (P4):** merit-order check: isotonic activation-MW → marginal-price curve per direction; **go only if it explains a useful share of price variance on up quarters (measure it — unverified)**; if go, blend into F_up/F_down tails; else cut.
7. **H14–20 (P4):** calibration pass — isotonic direction per step band, grouped conformal, p_none, quantile sorting; recency-weight ablation (1/2/3); DST unit test (duplicate local hour 25 Oct); two-fold per-column selection.
8. **H20–26 (all):** freeze, generate test predictions, sanity checks (coverage, sums, monotonicity, NaNs, 15-min spot alignment), final per-metric table.
9. **H24–32 (P5):** Level-2 dashboard + reasoning-chain report + video. This is 20% jury + 20 jury points — do not scrimp.

**Cut first, in order:** merit-order model → UMM → ICON spread (keep ECMWF only) → grouped conformal (fall back to global per step band) → 15-min-origin augmentation → Elering. **Never cut:** the harness, wind-error feature, calibration pass, submission validity checks.

## 6. The idea others won't think of

- **Forecast volume, map to price.** mFRR activation MW is smoother and more directly wind-error-driven than price. Learn the empirical merit-order curve (activation volume → marginal price, per direction, isotonic/monotone); spikes then emerge naturally from the steep segment of the curve instead of being pattern-matched. Fails if the curve is flat or drifts — that's what the H12 check is for. Either way it's a compelling jury narrative.
- **Per-column model selection.** Everyone assumes one model must produce all outputs; the scoring doesn't. Take p50 from a robust direct quantile model and the tails/spikes from the mixture if that wins on CV — free points, zero risk.
- **Spot-differenced price persistence** at steps 1–4: price level is more autocorrelated than the gap when spot ramps intra-day.

## 7. Risks and what to verify first

1. **Real-time wind availability/backfill** — the single biggest DQ risk. Email organisers in hour 1; keep a no-realtime-wind fallback; document the assumed delay in the report. If unconfirmed by H6, proceed with the 30-min assumption but state it.
2. **Thesis check (H3–4):** wind-error autocorrelation and predictive lift (experiment 2). If weak, re-plan around calibration and the mixture.
3. **Drift:** Sep std 141, up-share 35% → 25% in early Oct, spike shares train→val 9.0/7.3 → 12.1/13.0. Run rolling CV (train ≤ Aug, validate Sep) to measure robustness; prefer physical features (wind MW, solar, temperature proxy) over calendar months; test a P(up) intercept correction from the last 14 days — adopt only if it wins on both folds.
4. **Leak audit:** synthetic-data unit test of the origin builder; assert-based guards stay in the final pipeline (code will be reviewed).
5. **Validation overfitting via per-column selection:** two folds, select on the average.
6. **DST and alignment:** duplicate local hour on 25 Oct; spike thresholds use that quarter's own 15-min spot — verify alignment once.
7. **Estimate honesty:** every gain number in §3 is a judgement call; treat them as priors, and re-estimate from your own crowd-baseline numbers at H6 before allocating the remaining hours.
