# Notes for AI agents in this repository

- **Scores:** whenever you score a model on September (`validation`) or August (`fold_b`), log it on the team scoreboard by following [`scoreboard/README.md`](scoreboard/README.md). `python scoreboard/leaderboard.py` shows the current winner. Never score or log the test month (5 Oct – 1 Nov 2026).
- **Data rules:** an input row may be used only from its `first_usable_origin_utc`. Nord Pool spot prices are licensed: never commit or publish them.
